# Assessment — ECEG-4192

| Component | Weight | Timing |
|---|:---:|---|
| Assignments (4) | **30%** | Weeks 3, 7, 12, 16 |
| Tests (2) | **20%** | Weeks 6, 11 |

---

## Assignments (30%)

Four take-home assignments at **7.5% each**. Each mixes:

- **Written analysis** — complexity proofs, structural traces, comparison tables
- **Implementation** — working Java or Python code
- **Report** — justification of design choices

### Rubric (per assignment)

| Criterion | Weight |
|---|:---:|
| Correctness of analysis | 30% |
| Correctness of implementation | 30% |
| Code clarity and commenting | 20% |
| Interpretation and comparison with alternatives | 20% |

**Submission.** PDF report + source files in a `.zip`. Both uploaded to the LMS. **Late submissions: 10% per calendar day, zero after 3 days.**

---

## Tests (20%)

Two 45-minute in-class tests, **10% each**, closed book, one handwritten A4 formula sheet.

| Test | Covers | Learning outcomes |
|:---:|---|---|
| **Test 1** (week 6) | Ch 1–3 | LO1, LO2, LO3 |
| **Test 2** (week 11) | Ch 4–5 | LO4, LO5 |

**Structure.** 3–4 questions per test — a mix of complexity analysis, structural trace (e.g., "show the AVL tree after inserting 1..7"), and small implementation.

---

## Final examination (50%)

**3 hours, closed book**, one handwritten A4 formula sheet. Covers all chapters, roughly proportional to teaching hours:

| Chapter | Weight in final |
|---|:---:|
| 1 — Introduction & Big-O | 10% |
| 2 — Arrays | 8% |
| 3 — Linked Lists | 10% |
| 4 — Stacks & Queues | 12% |
| 5 — Trees | 20% |
| 6 — Hash Tables | 10% |
| 7 — Graphs | 20% |
| 8 — Sorting | 10% |

**Structure.** 5–7 multi-part questions:
- 2–3 structural problems (build a tree, trace a hash table, run a graph algorithm)
- 1–2 complexity analyses (prove Big-O of code)
- 1–2 comparison / design questions (which structure fits X, justify)

**Permitted on formula sheet:** Big-O table, tree rotation rules, hash probing formulas, sorting comparison table.
